# Publish This Project in 10–15 Minutes

The application code, machine-learning model, business logic, documentation and portfolio wording are already prepared. Your task is to upload, deploy and add your links.

## Part 1: Upload to GitHub — approximately 5 minutes

1. Sign in to GitHub.
2. Select the **+** button in the top-right corner, then **New repository**.
3. Repository name: `ai-customer-retention-dashboard`
4. Description: `Machine-learning decision-support dashboard for customer churn prediction and retention planning.`
5. Select **Public** and then **Create repository**.
6. Select **uploading an existing file**.
7. Upload these six files from the extracted project folder:
   - `app.py`
   - `requirements.txt`
   - `README.md`
   - `PROJECT-SUMMARY.md`
   - `LINKEDIN-AND-PERSONAL-STATEMENT.md`
   - `DEPLOY-IN-15-MINUTES.md`
8. Commit message: `Add AI customer retention dashboard`
9. Select **Commit changes**.

## Part 2: Deploy with Streamlit — approximately 5 minutes

1. Open `https://share.streamlit.io`.
2. Sign in using the same GitHub account.
3. Select **Create app**.
4. Choose your `ai-customer-retention-dashboard` repository.
5. Set the branch to `main`.
6. Set the main file path to `app.py`.
7. Select **Deploy**.
8. Wait for the application to build, then copy its public URL.

No API key, payment or secrets are required.

## Part 3: Finalise the evidence — approximately 3 minutes

1. Open `PROJECT-SUMMARY.md` in GitHub.
2. Select the pencil icon.
3. Replace `Add Streamlit link here` with your public application URL.
4. Replace `Add GitHub link here` with the repository URL.
5. Commit the change.
6. Add the live application URL to the repository's **About** section under **Website**.

## Part 4: Quick test — approximately 2 minutes

Confirm that:

- All four tabs open.
- The charts are visible.
- The customer-input sliders work.
- **Predict churn risk** returns a percentage and recommended actions.
- The business-impact calculator updates.
- The responsible-AI tab displays the model metrics and limitations.

Take screenshots of the Business Overview, Customer Prediction and Responsible AI tabs for use as evidence.
