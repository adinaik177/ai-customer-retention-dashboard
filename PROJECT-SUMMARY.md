# Project Summary: AI Customer Churn & Retention Dashboard

**Creator:** Aditya Naik  
**Project type:** Independent personal portfolio project

## Overview

I developed an interactive AI customer-retention dashboard to explore how machine learning can support a practical digital-business decision. The application uses fictional customer data to estimate churn risk, visualise retention patterns, recommend human-reviewed actions and calculate an illustrative business-value scenario.

## Business problem

Customer churn affects recurring revenue, customer-acquisition costs and business planning. The project considers how a digital business could use customer behaviour data to identify accounts that may need attention and prioritise appropriate retention activity.

## Work completed

- Defined the customer-retention problem and the intended decision workflow.
- Created a reproducible synthetic dataset covering spend, tenure, satisfaction, support activity, digital engagement and contract type.
- Built a supervised machine-learning pipeline using logistic regression.
- Separated training and test data and evaluated accuracy, ROC-AUC and classification errors.
- Created an interactive Streamlit interface for individual churn-risk predictions.
- Connected model predictions to transparent, human-reviewed business actions.
- Added KPI visualisations and a scenario-based customer-value calculator.
- Documented ethical considerations, limitations and responsible-AI controls.

## Skills demonstrated

Machine Learning, Artificial Intelligence, Digital Business, Predictive Analytics, Data Visualisation, Business Analysis, Python, Streamlit, Responsible AI, Decision Support and GitHub.

## Important limitation

This is an independent portfolio project using synthetic data. It is not professional employment experience or a production system. The project demonstrates self-directed learning and the application of introductory AI techniques to a digital-business problem.
